## Цель и критерий приёмки (§9-Ф5)

CRUD тегов/категорий (цвет) отражается в `/api/state`; экспорт — корректный markdown по
фикстуре. Дополнительно из `ANSWERS-F4.md`: кнопка «Отправить сейчас» (Q18) мелким коммитом
в эту ветку; аплоад не буферизуем (Q19); стриминг-аплоад — техдолг, взять по остатку.

## Решения фазы

1. **Порядок сортировки — локальная настройка устройства.** Контракт `PATCH /api/settings` знает
   только категорию по умолчанию, поэтому порядок списка живёт в DataStore (`SettingsStore`),
   а не в снапшоте сервера. Варианты: «По статусу» (как в Ф0), «По дате статуса», «По названию».
2. **Цвета — строка `#rrggbb`.** Единая нормализация (`CatalogColor.normalize`): `#RGB`,
   без решётки и в разном регистре → `#rrggbb`; мусор не отправляется, в диалоге показывается
   подсказка. Нормализация в VM, репозиторий отправляет как есть.
3. **Справочники — прямыми мутациями с рефетчем** (как сотрудники в Ф3): редкие действия,
   а сервер — источник правды по id/цветам. В офлайн-очередь не ставятся (PLAN-F4 §2.4).
4. **Экспорт — чистая функция** `MarkdownExport.build(snapshot, …)` над локальным снапшотом
   Room: строки статусов и форматирование даты приходят снаружи, поэтому формат проверяется
   JVM-тестом на фикстуре без Android. Отдаём через системный «Поделиться» (`text/plain`).
5. **Стриминг-аплоад (техдолг Q16).** `LocalFileSource` отдаёт `LocalFileHandle` (имя, mime,
   размер, ленивый `InputStream`), `StreamRequestBody` пишет файл в сокет частями — память не
   зависит от размера файла. `Content-Length` берётся из `OpenableColumns.SIZE`, при отсутствии —
   chunked.
6. **Кнопка «Отправить сейчас»** (Q18) в баннере очереди: триггерит тот же `SyncScheduler`, без
   новой логики отправки.

## Риски

| Риск | Страховка |
|---|---|
| Удаление тега/категории ломает задачи | сервер чистит ссылки; UI предупреждает в диалоге; рефетч после мутации |
| Неверный цвет уходит на сервер | `CatalogColor.normalize` + подсказка в диалоге, мусор не отправляется |
| Экспорт нестабилен | чистая функция, детерминированный порядок, тест на фикстуре (два вызова дают идентичный текст) |
| Стриминг с неизвестным размером | `contentLength = -1` → chunked; тест на `LocalFileHandle` |
| Сортировка не применяется | компаратор в домене + тест; список собирается через `TaskGroups.build` |

## Definition of Done

1. `clean test assembleDebug lintDebug` зелёный, lint без замечаний.
2. На моке: создать/переименовать/удалить тег и категорию → `/api/state` обновляется; категория
   по умолчанию меняется; сортировка переставляет список; экспорт отдаёт корректный markdown.
3. `PHASE-REPORT.md` + PR; живая приёмка — Алина на устройстве.
