# PLAN — Ф8: свайп-удаление везде

Ветка: `phase/8-swipe-everywhere` (от `main`) · Основание: `TZ-01-android-app.md` §5.2
(«удаление — M3 SwipeToDismissBox, смахивание влево, с подтверждением диалогом — ВЕЗДЕ»;
политика владельца: никаких видимых кнопок удаления)

## Что меняем

1. В редакторе задачи **подзадачи** удаляются свайпом влево (раньше — иконка-корзина).
2. В редакторе **вложения** удаляются свайпом влево (раньше — иконка-корзина).
3. Видимые кнопки удаления из редактора убираем полностью (остаются только на свайпе —
   красный фон с иконкой, виден в момент жеста).

## Решения

1. **Один общий компонент** `SwipeToDeleteRow` (ui/common): `SwipeToDismissBox` влево,
   диалог подтверждения, общий фон `DeleteSwipeBackground`. Он же переиспользован списком
   задач (там фон раньше был приватным дублем).
2. **Свайп не удаляет сразу**: строка возвращается на место (`dismissState.reset()`), решение
   принимает диалог — как в списке задач (ТЗ требует подтверждение).
3. **Непрозрачный фон строки обязателен.** Первая версия живой проверки показала «встроенные»
   корзины: фон свайпа (красный + иконка) просвечивал через прозрачный контент строки.
   Обёртка `Surface(color = surfaceContainerLow)` внутри `SwipeToDeleteRow` решает это.
4. **Порог свайпа** — треть ширины, чтобы случайный короткий жест не открывал диалог.
5. **Удаление подзадачи/вложения** идёт теми же путями, что раньше (кнопки лишь убраны):
   `TaskMutationRepository.delete` (очередь/офлайн) и `AttachmentRepository.delete` (сервер).
