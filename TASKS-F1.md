## Карточки

### F1-01 — Мок-сервер: мутации (исполнитель: субагент)

- **Файлы:** `tools/mock-server/mock_state_server.py`, `tools/mock-server/README.md`.
- **Что:** состояние в памяти из фикстуры; `POST /api/tasks` — список `TaskIn`, UPSERT полного
  объекта; `id: null` → новый id; при `updated_at` в теле и расхождении с текущим →
  `409 {"error":"conflict","actual_updated_at":…}`; `POST /api/tasks/{id}/toggle` `{status}`;
  `DELETE /api/tasks/{id}` — soft-delete задачи и всех потомков; после мутаций пересчитывать
  `ETag` и `server_time`; `status=completed` без `completed_at` → проставить `now`, при возврате
  в `created` — очистить; писать историю статусов при смене статуса.
- **DoD:** самопроверка по HTTP: создать `__ТЕСТ` → изменить → удалить; 409 при устаревшем
  `updated_at`; после удаления задача исчезает из `/api/state`; `ETag` меняется.
- **Запреты:** не менять фикстуру и `app/**`; токен/адрес не логировать.

### F1-02 — Тесты домена и сети (исполнитель: субагент)

- **Файлы:** `app/src/test/java/.../domain/**`, `.../data/repo/**`, `.../net/**`.
- **Что покрыть:** `TaskFilter` (дефолт «Активные» = created+inprogress; категории; теги;
  комбинации), группировка `▸ N/M` (фильтр статуса отбирает **только родителей**, дети
  показываются всегда — см. `PLAN-F1.md` §2 п.2), счётчики, авто-контраст, payload из сущности (все поля,
  `status_date == null`, `updated_at` только для существующей), исходы мутаций (upsert ok/409/401/
  403/500/IOException), `delete` → soft-delete исход, контракт HTTP для POST/DELETE (заголовки,
  тело, 409).
- **DoD:** ведущий прогоняет `:app:testDebugUnitTest` — зелёно, число тестов зафиксировано.
- **Запреты:** не менять `app/src/main/**`; Gradle не запускать.

### F1-03 — UI списка (владелец: ведущий)

- **Файлы:** `ui/list/**`, `ui/common/**`, `ui/MainScreen.kt`.
- **Что:** чипы фильтров с подписями и счётчиками, группы подзадач со сворачиванием и `▸ N/M`,
  чекбокс «Выполнена ↔ Создана», свайп-удаление с диалогом, бейджи (статус/теги/вложения/
  сотрудник).
- **DoD:** состояния Loading/Empty/Error остаются раздельными; «ничего не найдено» — отдельное
  состояние со сбросом фильтров; тач-таргеты ≥48dp.
