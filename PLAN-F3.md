Ветка: `phase/3-attachments` (от `main` после merge Ф2) · ТЗ §5.3-Ф3, §4, §6, §9-Ф3
· Ответы предыдущей фазы: `ANSWERS-F2.md`

## Цель и критерий приёмки (§9-Ф3)

Вложения: аплоад multipart (photo picker + «Поделиться в Задачи» = `ACTION_SEND`/`SEND_MULTI`),
превью картинок (Coil, `?token=`), открытие PDF/файлов внешним просмотрщиком (FileProvider),
шаринг наружу, удаление. Сотрудники: CRUD на экране настроек.

Приёмка: картинка из галереи и «Поделиться» из другого приложения долетают и видны в
существующих клиентах; PDF открывается внешним просмотрщиком; удаление вложения чистит и сервер.

## Решения фазы

1. **Coil 3** (`coil-compose` + `coil-network-okhttp`, Apache-2.0) — требование §5.1. Сеть
   превью идёт клиентом **без** интерсептора заголовков: у файла токен в query (`?token=`),
   ссылка абсолютная, а интерсептор подменил бы хост и добавил лишний заголовок.
2. **Ссылку на файл собирает отдельный чистый объект** `AttachmentUrls` (base + путь + токен):
   это единственное место, где токен попадает в URL, поэтому его легко покрыть тестом и
   нельзя случайно залогировать (логов HTTP нет).
3. **FileProvider** для открытия/шаринга: файл скачивается в приватный кэш
   (`cacheDir/attachments`), наружу отдаётся `content://` с временным правом чтения.
   Имя файла санитизируется (`safeAttachmentFileName`), чтобы чужое имя не вывело запись
   за пределы каталога.
4. **«Поделиться в Задачи»** — intent-filter на `MainActivity`; uri складываются в `ShareInbox`
   (живёт в контейнере, переживает пересоздание Activity), UI показывает выбор задачи из
   текущего фильтра и грузит файлы вложениями.
5. **После каждой мутации — `refresh()`** (вложения/сотрудники): id/размеры и переименования
   приходят с сервера, локальных догадок не делаем.

## Риски

| Риск | Страховка |
|---|---|
| Токен в URL утечёт в логи/кэш | HTTP-логирование выключено, ссылка собирается в одном месте, `Cache` — приватный каталог приложения |
| Имя файла из чужого приложения выведет запись из кэша | `safeAttachmentFileName` + тест на `../` |
| Открытие файла падает без просмотрщика | `AttachmentIntents.launch` возвращает `false`, UI показывает сообщение |
| Большой файл в память | чтение целиком в `LocalFileSource` (для MVP приемлемо); ограничение размера обсуждается в `QUESTIONS.md` |
| «Поделиться» без выбранной задачи | очередь в `ShareInbox` + явный диалог выбора, отмена доступна |

   CRUD сотрудников отражается в `/api/state`.
